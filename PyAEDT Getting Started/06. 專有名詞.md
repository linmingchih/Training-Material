06. 專有名詞
---
| 術語 | 說明 |
| --- | --- |
| PyANSYS | Ansys 官方維護的一系列開源 Python 函式庫統稱，涵蓋 PyAEDT、PyMechanical、PyFluent、PyEDB 等 |
| PyAEDT | PyANSYS 家族中專門自動化 AEDT 的 Python 套件 |
| AEDT | Ansys Electronics Desktop，Ansys 電子/電磁類模擬工具的統一工作環境 |
| Non-graphical | AEDT 不開圖形介面執行的模式，適合伺服器或批次作業 |
| HFSS / HFSS 3D Layout | AEDT 內用於三維全波電磁模擬（HFSS）與 PCB/封裝版圖導向模擬（HFSS 3D Layout）的模組 |
| Q3D | AEDT 內用於提取 RLCG 寄生參數的模組 |
| Circuit | AEDT 內用於電路原理圖模擬（Nexxim）的模組 |
| Icepak | AEDT 內用於熱模擬的模組 |
| Maxwell | AEDT 內用於低頻電磁（馬達、變壓器等）模擬的模組 |
| Port / Boundary | 模擬中的激勵源（Port）與邊界條件（Boundary）設定 |
| Sweep | 頻率掃描，指定模擬要計算的頻率點或頻段 |
| venv | Python 內建的虛擬環境工具 |
| uv | 新一代、速度較快的 Python 套件與虛擬環境管理工具 |
| gRPC | AEDT 對外提供的遠端程序呼叫介面，讓 PyAEDT / MCP 可以遠端連線控制 AEDT |
| MCP | Model Context Protocol，規範 AI 客戶端與外部工具伺服器間溝通方式的開放標準 |
| MCP Server | 實作 MCP 規格、將實際功能包裝成 Tool 供 AI 呼叫的伺服器程式 |
| Tools / Resources / Prompts | MCP 定義的三種核心能力：可執行的工具、只讀資料、可重複使用的任務模板 |
| Skill | 把重複出現的操作慣例與判斷標準，寫成 AI 可直接讀懂並重複使用的指令模板 |
| SKILL.md | 定義一個 Skill 的標準檔案，包含觸發時機與具體執行步驟 |
